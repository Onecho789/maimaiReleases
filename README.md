# 麦麦工坊

麦麦工坊安装包与更新发布仓库。

## 下载

[下载 Windows 安装包](https://github.com/Onecho789/maimaiReleases/releases/latest/download/MaiMaiStudio-Setup.exe) · [最新版本与更新说明](https://github.com/Onecho789/maimaiReleases/releases/latest)

支持 Windows 10/11（64 位）。macOS 安装包暂未发布。

## 客户端更新

从 2.1.31 起内置官方更新源，启动后检查新版本，可在「关于」中下载并选择重启安装。开发者设置中的自定义更新源优先，清空并保存后恢复官方源。

2.1.30 或更早版本的用户请先下载安装一次最新完整包，以启用默认官方更新源。

安装器、更新归档及更新清单作为对应版本的 Release 附件提供。版本名安装器与固定名 MaiMaiStudio-Setup.exe 内容相同。
